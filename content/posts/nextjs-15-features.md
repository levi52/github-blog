## Next.js 15 新特性

Next.js 15 带来了许多令人兴奋的新特性。

### Turbopack

Turbopack 是 Next.js 的新一代打包工具，比 Webpack 快 700 倍。

### Server Components

服务端组件让你可以在服务器上渲染组件，减少客户端 JavaScript 体积。

### Server Actions

Server Actions 让表单处理变得更加简单，无需编写 API 路由。

## 总结

Next.js 15 是一个重要的版本更新，值得升级尝试。
