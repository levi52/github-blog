## Welcome

This is my first blog post! I've built this blog using **Next.js** with static export, deployed on **GitHub Pages**.

## Features

- Markdown-based blog posts
- Categories and tags
- Full-text search
- Developer tools (JSON formatter, Base64, etc.)
- Responsive design

## Getting Started

To create a new post, add a Markdown file in the `content/posts/` directory with the following frontmatter:

```markdown
---
title: "Your Post Title"
date: "2026-08-30"
summary: "A brief summary of your post."
categories:
  - Category1
tags:
  - tag1
  - tag2
---

Your content here...
```

Happy blogging!
