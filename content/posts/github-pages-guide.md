## 什么是 GitHub Pages

GitHub Pages 是 GitHub 提供的免费静态网站托管服务。

## 部署步骤

### 1. 创建仓库

创建一个名为 `username.github.io` 的仓库。

### 2. 上传代码

将你的静态网站代码推送到仓库。

### 3. 启用 Pages

在 Settings -> Pages 中启用 GitHub Pages。

## 自定义域名

你可以绑定自己的域名到 GitHub Pages。
